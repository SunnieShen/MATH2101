### **二、子空间分解与交、和（对应 10(c)）**
**核心：** 子空间的交、和、直和，维数公式，分解的唯一性。
**高优先级：**
1. **作业4（第6页）第1题**  
   - 证明 \(W_1 + W_2\) 是子空间。
   - **原因**：理解和与分解的基本操作。

2. **作业5（第7页）第4题**  
   - 设 \(S_1, S_2\) 线性无关且 \(S_1 \cap S_2 = \emptyset\)，证明 \(S_1 \cup S_2\) 线性无关当且仅当 \(\text{span}(S_1) \cap \text{span}(S_2) = 0\)。
   - **原因**：涉及子空间交为零的条件，与 10(c) 反例构造相关。

3. **作业5（第7页）第5题**  
   - 设 \(d_1 = \dim N(A_1), d_2 = \dim N(A_2)\)，若 \(d_1 + d_2 > m\)，则存在非零公共解。
   - **原因**：涉及子空间交的维数不等式，深化理解。

4. **Exercise.pdf 第10页 3.3**  
   - 证明维数公式 \(\dim(U+V) + \dim(U \cap V) = \dim U + \dim V\)。
   - **原因**：基本工具，用于分析子空间结构。

5. **2101_22_dec.pdf 第4页 (15)**  
   - 证明 \(\dim(\operatorname{Im}(F) \cap \operatorname{Ker}(G)) = \dim(\operatorname{Ker}(G \circ F)) - \dim(\operatorname{Ker}(F))\)。
   - **原因**：更深入的子空间关系，锻炼证明能力。

**中优先级：**
6. **Exercise.pdf 第13页 4.8**  
   - 证明线性变换的图是子空间且是双射。
   - **原因**：涉及向量分解，较抽象。

### **三、矩阵的秩、列空间与 \(AA^T\) 性质（对应 12(a,b)）**
**核心：** 秩的性质，列空间与零空间，\(AA^T\) 的特殊性。
**高优先级：**
1. **作业2（第2页）第2题**  
   - 证明 \(\det(vv^T) = 0\)（\(n \geq 2\)）。
   - **原因**：理解秩1矩阵的行列式，联系到 \(AA^T\) 的秩。

2. **作业6（第8页）第4题**  
   - 给定 \(T(A) = PAQ\)，求 \(R(T)\) 和 \(N(T)\) 的基。
   - **原因**：直接计算像空间和零空间，训练秩、列空间、零空间的计算。

3. **ExercisesLinearTransformation.pdf 第2页 2(4)**  
   - 证明 \(\operatorname{rank}(U \circ T) \leq \operatorname{rank}(T)\) 且 \(\operatorname{nullity}(U \circ T) \geq \operatorname{nullity}(T)\)。
   - **原因**：秩的不等式，基本性质。

4. **Exercise.pdf 第20页 5.4**  
   - 验证相似矩阵有相同的迹、行列式、秩。
   - **原因**：秩在相似变换下的不变性。

5. **2101_22_dec.pdf 第4页 (16)**  
   - 若 \(A\) 奇异且 \(\operatorname{rank}(A) \neq \operatorname{rank}(A^2)\)，证明 0 的几何重数小于代数重数。
   - **原因**：联系秩与特征值重数，深化理解。

**中优先级：**
6. **ExercisesLinearTransformation.pdf 第2页 2(5)**  
   - 判断关于线性变换秩的命题。
